# WPS for Linux 功能测试计划

> 目标：在 **Omarchy + Hyprland** 下系统性验证 WPS Office 的日常功能，记录哪些正常、哪些有问题、以及可用的绕行方案。
> 测试结果会逐步补进 [`docs/test-reports/`](test-reports/)（每个版本一份）。

## 测试环境

| 项目 | 值 |
|---|---|
| 发行版 | Omarchy 4.5.0rc1（Arch Linux） |
| 内核 | linux-omarchy 7.2.8-9 |
| 合成器 | Hyprland 0.56.2（Lua 配置） |
| WPS | wps-office-365 12.1.2.29183-1（AUR） |
| 运行方式 | XWayland |
| 显示 | 1920×1080 @ 1.25 缩放（笔记本内置屏） |
| 输入法 | fcitx5 |
